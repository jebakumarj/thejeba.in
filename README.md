# Jebakumar J - Developer Portfolio

Personal portfolio built with HTML, Tailwind CSS, and JavaScript. Live at [thejeba.in](https://thejeba.in).

## Features

- **3 themes**: 🍱 Bento, ⚡ Modern, 🌌 Cyber, switched instantly from a floating bar
- **Dark & light mode**, remembered across visits
- **No scrolling on desktop**: every layout fits the screen
- **Featured projects**: thirukkural.xyz, md-kanban, md-manager, kaasu-android, deckdown
- **Live GitHub star counts** on each project card
- **Contact form** powered by Netlify Forms
- **Accessible**: AA color contrast, reduced-motion support
