# Jebakumar J — Multi-Theme Developer Portfolio

A minimalist, high-performance developer portfolio built with **HTML5**, **Tailwind CSS**, and **JavaScript**, featuring an instant **3-Theme Layout Switcher** and **Dark/Light Mode** support.

## 🎨 3 Distinct Themes Included

1. **🍱 Bento Grid Theme**: Inspired by modern bento layouts, featuring a periwinkle profile hero block, mint & lavender stat cards, spinning vinyl badge, and media preview card for `thirukkural.xyz`.
2. **⚡ Sharp Modern Theme**: The sharp single-card dashboard design featuring a 360° rotating glowing border, 4-side ambient background aura, and floating programming tech badges.
3. **🌌 Cyber Neon Theme**: High-contrast synthwave cyberpunk layout with neon glow card borders.

## ✨ Core Features

- 🎛️ **Multi-Theme Switcher**: Fixed floating control bar to switch between Bento, Modern, and Cyber layouts with zero page reload.
- 🌓 **Dark & Light Mode**: Instant mode toggle button persisting in `localStorage`.
- 🚀 **Featured Projects Grid**: Showcases `thirukkural.xyz`, `kaasu-android`, `md-kanban`, `md-manager`, and `homepage`.
- 📬 **Direct Contact Form**: Netlify Forms enabled contact form with instant AJAX feedback.
